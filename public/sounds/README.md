# Sound Files for Price Alerts

This directory should contain sound files for price alerts:

- `alert-buy.mp3` - Sound played when a buy alert is triggered
- `alert-sell.mp3` - Sound played when a sell alert is triggered

These files are currently placeholders. Add actual sound files to enable audio alerts.

You can use free sound effects from sources like:
- https://freesound.org/
- https://www.zapsplat.com/
- https://mixkit.co/free-sound-effects/

Suggested sounds:
- Buy alert: Gentle notification or coin sound
- Sell alert: Success or level-up sound
