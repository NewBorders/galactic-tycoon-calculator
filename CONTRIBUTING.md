# Contributing

This repository uses **upstream branches + pull requests**. Forks are not required.

## Requesting write access
By default, only maintainers can push.  
If you want to contribute:

1. Open an issue titled **"Access request: <your GitHub username>"**.
2. Briefly describe what you plan to work on, ideally addressing existing github issues.
3. A maintainer will grant temporary write access if it makes sense.

Write access may be removed anytime if rules are ignored.

## Working with branches
- Never push to `main` (branch is protected).
- Create your own feature/fix branches.
- Keep changes focused and reasonably small.

## Pull requests
- Open a PR against `main`.
- Explain what you changed and why.
- Link related issues if possible.
- At least one approval is required before merging.
- Do not merge your own PRs without review.

## Issues
Feel free to create issues for bugs, ideas, questions or discussions before starting work.
